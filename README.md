### 🧠 5. Edge Scripting — Serverless Compute at the Edge

**Bunny Edge Scripting** lets you deploy custom **JavaScript code** at the edge, enabling you to build and run serverless logic closer to your users than ever before. Instead of routing requests all the way back to an origin server, your code executes within milliseconds of the user — at the edge node nearest to them.

Use cases for Edge Scripting:
- **A/B testing** without latency penalties
- **Request/response header manipulation**
- **Dynamic redirect logic**
- **JWT token validation at the edge**
- **Personalized content delivery**
- **Rate limiting and bot filtering**
- **Custom authentication flows**
